# Food Delivery — Restaurant Order Intelligence

## Overview

This project analyzes a food delivery and restaurant marketplace dataset using core Python.

The objective is to build a reusable analytics system without using Pandas, NumPy, SQL, Excel formulas, or external analytics libraries.

The project demonstrates:

- Python data structures
- Functions
- Searching
- Sorting
- Grouping
- Frequency counting
- Dictionary optimization
- Sequence analysis
- Data validation
- Object-Oriented Programming
- Inheritance
- Polymorphism
- Exception handling
- Business analysis
